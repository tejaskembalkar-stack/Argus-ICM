# Review Pass

1. Review the complete diff or artifact independently of implementation.
2. Check acceptance criteria, regressions, security, secrets, boundary violations, and missing tests.
3. Run or inspect the highest-value verification again.
4. Fix confirmed issues and re-run affected checks.
5. Update `.brain/NOW.md`; promote only verified reusable lessons to `.brain/memory/`.
6. Report changed, verified, blocked, and remaining items separately.

Output: verified completion or explicit blockers.
